# Position Monitor

`mt5-position-monitor` — MT5の表示専用ポジション監視インジケータ（MT5上の名前: PositionMonitor）。

## リポジトリ構成

```text
src/PositionMonitor.mq5        ソースコード
src/PositionScenarioPanel.mqh  インジケータ内の仮TP/SL試算
build/PositionMonitor.ex5      コンパイル済みインジケータ
build/PositionMonitor.compile.log  コンパイル結果
src/PositionScenario.mq5       旧仮TP/SLの一回実行試算スクリプト
src/ClearPositionScenario.mq5  旧仮TP/SL試算の表示を消すスクリプト
src/ShowTradeLevels.mq5      MT5標準の取引レベル表示をオンにするスクリプト
build/PositionScenario.ex5     コンパイル済み試算スクリプト
build/ClearPositionScenario.ex5 コンパイル済み表示消去スクリプト
build/ShowTradeLevels.ex5      コンパイル済み取引レベル表示スクリプト
build/PositionScenario.compile.log  コンパイル結果
verification/tp-sl.json        TP・SL計算の検証記録（v1.00）
verification/rates.json        損益分岐・ロスカット計算の検証記録
```

検証記録のポジション数・損益等は作成時点のスナップショットで、現在値ではありません。

MT5のメインチャートに、保有ポジションのTP・SL到達時損益を表示するインジケータです。
作者名・宣伝・リンク・タイマーは表示しません。売買・注文変更・通信・DLLは実装していません。

## 導入

この環境では接続先MT5の `MQL5\Indicators\Custom\PositionMonitor.ex5` に配置済みです。
別のMT5に導入する場合は、`build/PositionMonitor.ex5` をそのMT5のデータフォルダ内の同じ場所にコピーしてください。

1. MT5のナビゲータで「インディケータ」を右クリックし「更新」。
2. `Custom → PositionMonitor` をBTCUSDチャートへドラッグ。
3. 最初は既存のSummary Risk Targetと金額を照合してください。
4. 一致と表示位置を確認後、不要なら既存インジケータだけを削除できます。

BTCUSDチャートへのMCP設置と起動を確認済みです。コンパイルは0 errors / 0 warnings。
MCPの実行時バッファでTP合計18,813 USD、SL合計-2,187 USD、損益分岐80,481.30、ロスカット目安80,899.3136を照合しました（2026-10-25のスナップショット）。
桁揃えの自己チェックを通過して起動していますが、描画結果のスクリーンショット確認は未実施です。

MT5標準のポジション・TP・SLラインが非表示になった場合は、該当チャートで `Scripts\Custom\ShowTradeLevels` を実行すると、そのチャートの取引レベル表示設定だけをオンにできます。注文・ポジション・TP・SLの値は変更しません。ラインの価格がチャートの表示範囲外にある場合は、表示設定がオンでも画面内には見えません。

## 初期表示

損益分岐・ロスカットのレートはMT5の銘柄情報 `SYMBOL_DIGITS` に合わせて表示します。例えばBTCUSDが0桁なら整数、USDJPYが3桁なら小数3桁です。内部計算は丸めずに保持し、損益金額・維持率の小数表示は維持します。USDJPYのように口座通貨が基軸通貨のFX銘柄は、損益通貨を換算して推定レートを「概算」として表示します。

TP・SL・損益分岐・ロスカット・維持率の数値を共通の右端に揃え、通貨・%・注記を別列に配置します。維持率も小数2桁にして小数点位置を揃えます。

全項目・数値のフォントをInpFont（初期値Meiryo）に統一しています。TP/SLの主金額は共通の右端へピクセル座標で整列し、円換算・注意書きは別の表示部品として配置します。

メインチャート左下（左15px・下25px）、文字サイズ11、3桁カンマ区切り・小数2桁です。
チャートのローソク足やラインと数値が重ならないよう、既定で表示全体の背後に濃色の背景を敷きます。`InpShowBackground` で表示を切り替え、`InpBackgroundColor` で色を変更できます。背景は表示行数と4桁分の数値幅に合わせて配置し、表示中の数値の桁が変わっても幅を縮めません。
チャート右上の「監視を隠す」「試算を隠す」ボタンで、PositionMonitorとPositionScenarioの表示を個別に隠せます。隠した後は同じボタンから再表示できます。試算パネルはPositionMonitorが管理します。表示の切り替えはチャート上の描画だけに作用し、注文やTP・SLは変更しません。PositionMonitorを外すと試算パネルと両方のボタンも消えます。
上から銘柄と件数、チャート銘柄のTP合計(銘柄)・SL合計(銘柄)、TP合計(口座)・SL合計(口座)、現在価格、損益分岐、ロスカット目安、現在損益(銘柄)・現在損益(口座)、口座の残高・有効証拠金・必要証拠金・余剰証拠金、証拠金維持率を表示します。口座全体のTP/SL行は `InpCurrentSymbolOnly=true` かつ `InpShowAccountTotals=true` のときに表示します。全銘柄表示では既存のTP/SL合計が口座全体に相当するため重複しません。現在価格は損益分岐・ロスカットとの比較のため、それらの推定レートと同じ価格基準で表示します。TP合計・SL合計・現在損益には、現在の口座残高に対する増減率を「+448.53 %」の形で併記します。損益率とpipsには共通の数値幅を使い、%記号とpipsの開始位置を揃えます。損益分岐・ロスカットのpipsとレート差は「+123.0 pips   +123」の順で表示します。比率、レート差、維持率のストップアウト注記は括弧や縦線を使わず、空白で区切って列を揃えます。現在損益(銘柄)はチャート銘柄の `POSITION_PROFIT + POSITION_SWAP` を合算し、現在損益(口座)はMT5の `ACCOUNT_PROFIT` を表示します。ThreeTraderのこの口座では口座値にも発生済みスワップが反映されるため、保有銘柄が1つなら両行の基準が揃います。現在損益のプラスは青、マイナスは赤、ゼロは補助色で表示します。
ヘッダーには「23 ポジション | 11 ロット」の形式で集計対象の件数とロット数を表示します。ロット数は保有ポジションの数量を足し、不要な小数のゼロを省いて最大8桁まで表示します。スワップ設定はヘッダーに表示しませんが、計算への反映は入力設定に従います。Ask/Bidは通常表示から省き、価格基準の説明をツールチップに残しています。計算方法は変更していません。
損益分岐・ロスカット・口座情報・証拠金維持率は項目名と数値を共通の列に整列します。主数値と通貨・概算の列を項目名から20px右へ寄せ、右側の損益率を14px右へ寄せ、pips・レート差の位置は維持します。右側の補助数値には整数部4桁分以上の幅を確保します。レート差は表示文字幅に応じて空き幅の中で左へ寄せ、pipsと重ならないようにします。BTCUSDのような整数価格の銘柄では、pipsとレート差の列を追加で右へ寄せ、チャート右端に最低6pxを残します。ストップアウトの注記は4桁欄より少し右に配置し、証拠金維持率の数値自体は幅調整の対象外とします。必要証拠金固定とSL/TPの途中決済を考慮しない計算上の仮定はツールチップに記載します。MT5から取得したストップアウト基準は証拠金維持率行に表示します。マージンコール基準の数値は表示しませんが、証拠金維持率が400%未満なら黄色、マージンコール基準以下なら赤色にします。赤色が優先されます。

## 損益分岐・ロスカット推定レート

損益分岐は「現在チャートの銘柄」の合計損益がゼロになる価格です。TP/SL合計の全銘柄設定とは独立しています。設定に応じて現在Swapと入力済み決済手数料を反映します。売りのみはAsk、買いのみはBid、両建ては現在スプレッドを固定したBid換算で表示します。

ロスカット目安は、現在の口座全体の必要証拠金を固定し、MT5口座から取得した強制ロスカット基準に有効証拠金が達するように現在チャート銘柄だけが動いた場合の価格です。口座の `ACCOUNT_MARGIN_SO_MODE` が割合なら基準は%で、金額なら口座通貨で扱います。`InpStopOutPercent` に正数を指定した場合のみ、その%を計算に使います。基準が取得できなければ推定レートは「基準取得不可」と表示します。他銘柄の損益・為替・スプレッド、建玉数量は固定します。現在までのSwapは口座有効証拠金に既に含まれるため、InpIncludeSwap=falseの場合もロスカット計算から除外しません。決済手数料も強制決済前の有効証拠金から追加で控除しません。

これは最初の強制決済が始まる仮定上の目安であり、全ポジションがその価格で決済される意味ではありません。必要証拠金の価格連動・レバレッジ変更・SL/TPでの途中決済・他銘柄の変動・ギャップにより変わります。設定済みSL/TPが先に執行されれば建玉が変わるため、表示レートは実際の経路を表しません。

レート推定は、損益通貨と口座通貨が一致する線形契約（USD口座・BTCUSDなど）に対応します。加えて、口座通貨が基軸通貨のFX銘柄（USD口座・USDJPYなど）で同方向の建玉のみの場合は、仮の決済価格で損益通貨を口座通貨に換算して概算します。現在のスプレッドを固定し、利益側は仮のAsk、損失側は仮のBidを換算に使います。換算レート、スプレッド、必要証拠金などが変われば実際の損益分岐・強制決済レートも変わります。口座通貨が基軸通貨でない通貨ペアや両建てなど対応外は「計算不可」と表示します。必要証拠金0、保有なし、正の価格に解なしも区別します。

計算式: 維持率=有効証拠金÷必要証拠金×100。基準が%なら有効証拠金の目標値=必要証拠金×強制ロスカット基準÷100。基準が口座通貨ならその金額を有効証拠金の目標値にします。マージンコールも同じ単位で取得し、%基準なら維持率、金額基準なら有効証拠金と比較します。
2026-10-25のMT5実行ログでは、口座基準は割合モード、マージンコール80%、ストップアウト20%、手動上書きなしでした。これらは口座の現在設定から再取得され、固定値として埋め込まれていません。
参考: https://www.mql5.com/en/book/automation/account/account_margin

## 計算の意味

- 保有ポジションのみ。予約注文は対象外。
- 建値から各ポジションの設定TP/SLで決済した場合の損益。現在値からの追加損益ではありません。
- TPを分けている場合は、それぞれの価格で決済した結果を合算。
- SLが利益側にある場合は、その利益をSL合計に表示。TP合計へ付け替えません。
- TP/SL未設定があれば該当する合計行は設定済みポジションの部分合計金額を残し、その横に「未設定あり」と表示します。項目名・金額・単位・警告を黄色にし、残高に対する増減率は表示しません。
- 対応外の計算方式や必要データ不足なら「計算不可」。誤ったゼロに置き換えません。
- USD建て口座のBTCUSDのような線形契約は、価格差×契約サイズ×lotで計算。口座通貨と損益通貨が異なる場合は現在の口座通貨建てティック価値を使用。
- スプレッドは決済価格へ追加で引きません。指定TP/SL価格での約定を前提とします。滑り・ギャップ・途中の強制決済・将来の為替変動を予測しません。
- 将来スワップ・支払済みのエントリー手数料は含みません。決済手数料は入力した額のみ。
- 円換算は表示時の参考レート。1時間以上古いレートなら日時（MT5サーバー時刻）を併記。
- 100msごとに更新します。値が変わったラベルだけを書き換え、文字幅が変わったときに列揃えを再計算します。

## 仮TP/SLの試算

仮TP/SLの試算は `PositionMonitor` インジケータに統合しています。設定画面の `InpTrialTP`・`InpTrialSL` に仮価格を入力すると試算パネルが表示されます。両方0なら初期表示は隠れ、「試算を表示」ボタンから開けます。「試算を隠す」で非表示にでき、再表示時には再計算します。`InpScenarioAlignRight`、`InpScenarioX`、`InpScenarioY` で試算パネルの位置を設定します。インジケータを外すと試算パネルと両方のボタンも消えます。

旧 `PositionScenario` と `ClearPositionScenario` は互換用としてリポジトリに残します。統合版では不要なため、MT5ターミナルからは取り外しています。

`InpTrialTP` と `InpTrialSL` に仮の価格を入力します。表の上にTP(変更予定)・SL(変更予定)を縦2行で表示し、「全11 ロット変更」「半数5 ロット変更」のように実際の対象ロット数を入れた両列に同じ仮価格を適用します。0なら「未入力」と表示してその項目の変更列と差額欄は「0 USD」とします。現在設定のTP/SLに未設定があれば該当する「現在の損益」列は「未設定あり」、設定済みでも計算できなければ「算出不可」と区別します。見出しにはポジション数と半数変更の対象数を明示します。現在のチャート銘柄の保有ポジションについて、現在設定、全件を仮価格に変更、半数だけを仮価格に変更した場合の合計損益と、現在設定からの差額をTP/SL別に表示します。背景パネルは選択した側のチャート内に配置し、既定の上端距離は25pxです。TP到達とSL到達は別々の仮定で、価格到達の順序は予測しません。実際のTP/SL・注文・ポジションは変更しません。
SLの仮設定は赤色で表示します。合計金額と差額は損益の符号に応じた色で表示します。TP・SLの変更予定価格が未入力の試算欄と差額欄には白色で「0 USD」のように表示し、試算値ではないことを仮設定欄の「未入力」で示します。「未設定あり」は黄色、その他の「算出不可」は警告色で表示します。

表の上に「現在損益(銘柄)」と「現在損益(口座)」を縦2行で表示します。銘柄側は `POSITION_PROFIT + POSITION_SWAP` の合計、口座側はMT5の `ACCOUNT_PROFIT` です。TPとSLそれぞれの下段の「TP合計(口座)」「SL合計(口座)」は、他銘柄も各ポジションの現在設定TPまたはSLで決済されたと仮定した予定合計です。「現在の損益」列は全銘柄の現在TP/SL、全件変更・半数変更列は現在チャート銘柄だけを仮価格に変更し、他銘柄のTP/SLは維持した見込額です。いずれかの銘柄にTP/SL未設定があれば、該当する口座全体の予定合計は「未設定あり」、設定済みでも計算できなければ「算出不可」とします。TP/SL試算へのスワップ算入は `InpIncludeSwap` に従い、将来の価格経路やスワップ変化は予測しません。口座残高や確定損益はこの「口座全体」に加えません。

半数は、各ポジションの**現在TPでの見込利益が小さい順**に選びます。奇数件では端数を切り捨て、同額ならチケット番号の小さい順です。列見出しの「半数」のロット数は選ばれたポジションの実ロット合計です。TPとSLの半数試算には同じポジションを使い、残りのポジションには現在設定を適用します。現在TPが未設定または計算不可なら半数を選べないため、半数試算は「算出不可」と表示します。

統合版の損益は、MT5のインジケータで `OrderCalcProfit` を呼べないため、PositionMonitorのTP/SL合計と同じ銘柄情報・ティック価値による推定計算を使います。設定に応じて発生済みスワップと入力した将来の決済手数料を反映します。USDJPYなど損益通貨と口座通貨が異なる場合は試算時点のティック価値で換算する概算です。将来TP/SLに到達した時の為替レートで換算した額とは異なり得るため、画面に「為替換算は試算時点」と表示します。旧スクリプトの計算には `OrderCalcProfit` を使います。現在TP/SLが未設定の場合、その合計は「未設定あり」、現状との差額は「差額 ―」と表示します。将来のスワップ、滑り、価格到達前の部分決済、ブローカーによるTP/SL価格の許可判定は含みません。試算額は仮価格やポジションの設定が変わったときに再計算し、現在損益は表示中に約1秒間隔で更新します。
