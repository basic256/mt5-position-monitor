# Clean TP SL Totals

`mt5-position-monitor` — MT5の表示専用ポジション監視インジケータ。

## リポジトリ構成

```text
src/CleanTPSLTotals.mq5        ソースコード
build/CleanTPSLTotals.ex5      コンパイル済みインジケータ
build/CleanTPSLTotals.compile.log  コンパイル結果
verification/tp-sl.json        TP・SL計算の検証記録（v1.00）
verification/rates.json        損益分岐・ロスカット計算の検証記録
```

検証記録のポジション数・損益等は作成時点のスナップショットで、現在値ではありません。

MT5のメインチャートに、保有ポジションのTP・SL到達時損益を表示するインジケータです。
作者名・宣伝・リンク・タイマーは表示しません。売買・注文変更・通信・DLLは実装していません。

## 導入

この環境では接続先MT5の `MQL5\Indicators\Custom\CleanTPSLTotals.ex5` に配置済みです。
別のMT5に導入する場合は、`build/CleanTPSLTotals.ex5` をそのMT5のデータフォルダ内の同じ場所にコピーしてください。

1. MT5のナビゲータで「インディケータ」を右クリックし「更新」。
2. `Custom → CleanTPSLTotals` をBTCUSDチャートへドラッグ。
3. 最初は既存のSummary Risk Targetと金額を照合してください。
4. 一致と表示位置を確認後、不要なら既存インジケータだけを削除できます。

MCPは配置直後の新ファイルを認識せず、チャートへの自動追加は未完了です。コンパイルは0 errors / 0 warnings。実チャートの描画・計算実行はまだ検証していません。

## 初期表示

メインチャート左下（左15px・下25px）、文字サイズ14、3桁カンマ区切り・小数2桁です。
上から銘柄と件数、TP合計、SL合計、損益分岐、ロスカット目安、証拠金維持率を表示します。金額の符号に応じて緑・赤になります。

## 設定

| 入力 | 内容 |
|---|---|
| InpCurrentSymbolOnly | trueで現在チャートの銘柄のみ。falseで全銘柄 |
| InpIncludeSwap | 現在までの累積スワップをTP/SLそれぞれのシナリオに算入 |
| InpExitCommissionPerLot | 将来の決済手数料を口座通貨・1lot片道の正数で入力。初期値0 |
| InpCorner | 左下が初期値。四隅を選択可能 |
| InpX / InpY | 選択した隅から表示ブロックまでの距離 |
| InpFontSize / InpFont | 文字サイズ・フォント |
| InpRowSpacing | 行間。文字の重なりを抑える最小間隔も適用 |
| InpDecimals | 小数桁数。0で整数 |
| InpShowHeader | falseで銘柄・件数のヘッダーを非表示。TP/SLの2行のみにする場合はInpShowRatesとInpShowMarginLevelもfalse |
| InpShowJPY | trueで円換算を併記。気配値に対応する直接/逆換算銘柄が必要 |
| InpShowRates | 現在チャート銘柄の損益分岐とロスカット推定レートを表示 |
| InpStopOutPercent | ロスカット基準。ユーザー指定のThreeTrader 20%を初期値に設定 |
| InpShowMarginLevel | 口座全体の現在の証拠金維持率を表示 |

## 損益分岐・ロスカット推定レート

損益分岐は「現在チャートの銘柄」の合計損益がゼロになる価格です。TP/SL合計の全銘柄設定とは独立しています。設定に応じて現在Swapと入力済み決済手数料を反映します。売りのみはAsk、買いのみはBid、両建ては現在スプレッドを固定したBid換算で表示します。

ロスカット目安は、現在の口座全体の必要証拠金を固定し、口座有効証拠金がその20%になるように現在チャート銘柄だけが動いた場合の価格です。他銘柄の損益・為替・スプレッド、建玉数量は固定します。現在までのSwapは口座有効証拠金に既に含まれるため、InpIncludeSwap=falseの場合もロスカット計算から除外しません。決済手数料も強制決済前の有効証拠金から追加で控除しません。

これは最初の強制決済が始まる仮定上の目安であり、全ポジションがその価格で決済される意味ではありません。必要証拠金の価格連動・レバレッジ変更・SL/TPでの途中決済・他銘柄の変動・ギャップにより変わります。推定レートまでにSL/TPが位置する場合は「SL/TP先行」と表示します。その場合は設定済みSL/TPが通常執行されれば建玉が変わるため、表示レートは実際の経路を表しません。

レート推定は損益通貨と口座通貨が一致する線形契約のみ対応します（現在のUSD口座・BTCUSDは対応）。対応外や完全両建ては「計算不可」等で表示し、推定値を捏造しません。必要証拠金0、保有なし、正の価格に解なしも区別します。

計算式: 維持率=有効証拠金÷必要証拠金×100。固定証拠金での基準有効証拠金=必要証拠金×InpStopOutPercent÷100。
参考: https://www.mql5.com/en/book/automation/account/account_margin

## 計算の意味

- 保有ポジションのみ。予約注文は対象外。
- 建値から各ポジションの設定TP/SLで決済した場合の損益。現在値からの追加損益ではありません。
- TPを分けている場合は、それぞれの価格で決済した結果を合算。
- SLが利益側にある場合は、その利益をSL合計に表示。TP合計へ付け替えません。
- TP/SL未設定があれば「未設定 n件・一部合計」と表示し、数値を警告色にします。
- 対応外の計算方式や必要データ不足なら「計算不可」。誤ったゼロに置き換えません。
- USD建て口座のBTCUSDのような線形契約は、価格差×契約サイズ×lotで計算。口座通貨と損益通貨が異なる場合は現在の口座通貨建てティック価値を使用。
- スプレッドは決済価格へ追加で引きません。指定TP/SL価格での約定を前提とします。滑り・ギャップ・途中の強制決済・将来の為替変動を予測しません。
- 将来スワップ・支払済みのエントリー手数料は含みません。決済手数料は入力した額のみ。
- 円換算は表示時の参考レート。1時間以上古いレートなら日時（MT5サーバー時刻）を併記。
- 1秒ごとおよびティック受信時に更新します。

## 検証

`verification/tp-sl.json` と `verification/rates.json` に独立した算式の検証とMT5ポジションの照合値を保存しています。
インジケータは起動時に金額整形の自己チェックも実行します。
計算仕様はMetaQuotesの https://www.mql5.com/en/book/automation/experts/experts_ordercalcprofit に従っています。
