# Position Monitor

`mt5-position-monitor` — MT5の表示専用ポジション監視インジケータ（MT5上の名前: PositionMonitor）。

## リポジトリ構成

```text
src/PositionMonitor.mq5        ソースコード
build/PositionMonitor.ex5      コンパイル済みインジケータ
build/PositionMonitor.compile.log  コンパイル結果
src/PositionScenario.mq5       仮TP/SLの一回実行試算スクリプト
build/PositionScenario.ex5     コンパイル済み試算スクリプト
build/PositionScenario.compile.log  コンパイル結果
verification/tp-sl.json        TP・SL計算の検証記録（v1.00）
verification/rates.json        損益分岐・ロスカット計算の検証記録
```

検証記録のポジション数・損益等は作成時点のスナップショットで、現在値ではありません。

MT5のメインチャートに、保有ポジションのTP・SL到達時損益を表示するインジケータです。
作者名・宣伝・リンク・タイマーは表示しません。売買・注文変更・通信・DLLは実装していません。

## 導入

この環境では接続先MT5の `MQL5\Indicators\Custom\PositionMonitor.ex5` に配置済みです。
別のMT5に導入する場合は、`build/PositionMonitor.ex5` をそのMT5のデータフォルダ内の同じ場所にコピーしてください。

1. MT5のナビゲータで「インディケータ」を右クリックし「更新」。
2. `Custom → PositionMonitor` をBTCUSDチャートへドラッグ。
3. 最初は既存のSummary Risk Targetと金額を照合してください。
4. 一致と表示位置を確認後、不要なら既存インジケータだけを削除できます。

BTCUSDチャートへのMCP設置と起動を確認済みです。コンパイルは0 errors / 0 warnings。

## 初期表示

損益分岐・ロスカットのレートはMT5の銘柄情報 `SYMBOL_DIGITS` に合わせて表示します。例えばBTCUSDが0桁なら整数、USDJPYが3桁なら小数3桁です。内部計算は丸めずに保持し、損益金額・維持率の小数表示は維持します。なお、表示桁数の対応とレート推定の計算対応は別であり、損益通貨と口座通貨が異なる銘柄のレート推定は現状「計算不可」です。

TP・SL・損益分岐・ロスカット・維持率の数値を共通の右端に揃え、通貨・%・注記を別列に配置します。維持率も小数2桁にして小数点位置を揃えます。

全項目・数値のフォントをInpFont（初期値Meiryo）に統一しています。TP/SLの主金額は共通の右端へピクセル座標で整列し、円換算・注意書きは別の表示部品として配置します。

メインチャート左下（左15px・下25px）、文字サイズ11、3桁カンマ区切り・小数2桁です。
上から銘柄と件数、TP合計、SL合計、現在価格、損益分岐、ロスカット目安、現在損益、口座の残高・有効証拠金・必要証拠金・余剰証拠金、証拠金維持率を表示します。現在価格は損益分岐・ロスカットとの比較のため、それらの推定レートと同じ価格基準で表示します。TP合計・SL合計・現在損益には、現在の口座残高に対する増減率を「+448.53 %」の形で併記します。損益率とpipsには共通の数値幅を使い、%記号とpipsの開始位置を揃えます。損益分岐・ロスカットのpipsとレート差は「+123.0 pips   +123」の順で表示します。比率、レート差、維持率のストップアウト注記は括弧や縦線を使わず、空白で区切って列を揃えます。現在損益と口座情報は、現在のチャート銘柄だけでなく口座全体の値です。現在損益のプラスは青、マイナスは赤、ゼロは補助色で表示します。
ヘッダーには「23 ポジション | 11 ロット」の形式で集計対象の件数とロット数を表示します。ロット数は保有ポジションの数量を足し、不要な小数のゼロを省いて最大8桁まで表示します。スワップ設定はヘッダーに表示しませんが、計算への反映は入力設定に従います。Ask/Bidは通常表示から省き、価格基準の説明をツールチップに残しています。計算方法は変更していません。
損益分岐・ロスカット・口座情報・維持率は項目名と数値を共通の列に整列します。右側の損益率・pips・レート差には整数部4桁分以上の幅を確保し、999から1,000への変化で列が動かないようにします。ストップアウトの注記はこの4桁欄の開始位置に固定し、維持率の数値自体は幅調整の対象外とします。必要証拠金固定とSL/TPの途中決済を考慮しない計算上の仮定はツールチップに記載します。MT5から取得したストップアウト基準は維持率行に表示します。マージンコール基準の数値は表示しませんが、維持率が400%未満なら黄色、マージンコール基準以下なら赤色にします。赤色が優先されます。

## 設定

| 入力 | 内容 |
|---|---|
| InpCurrentSymbolOnly | trueで現在チャートの銘柄のみ。falseで全銘柄 |
| InpIncludeSwap | 現在までの累積スワップをTP/SLそれぞれのシナリオに算入 |
| InpExitCommissionPerLot | 将来の決済手数料を口座通貨・1lot片道の正数で入力。初期値0 |
| InpCorner | 左下が初期値。四隅を選択可能 |
| InpX / InpY | 選択した隅から表示ブロックまでの距離 |
| InpFontSize / InpFont | 文字サイズ・フォント |
| InpRowSpacing | 行間。0（初期値）なら文字サイズに合わせて自動調整。正数ならそのpx値を固定 |
| InpDecimals | 小数桁数。0で整数 |
| InpShowHeader | falseで銘柄・件数・合計ロット数のヘッダーを非表示。TP/SLの2行のみにする場合はInpShowRates、InpShowCurrentProfit、InpShowAccountDetails、InpShowMarginLevelもfalse |
| InpShowJPY | trueで円換算を併記。気配値に対応する直接/逆換算銘柄が必要 |
| InpShowRates | 現在チャート銘柄の現在価格・損益分岐・ロスカット推定レートを表示 |
| InpStopOutPercent | 0（初期値）でMT5口座の強制ロスカット基準を自動取得。正数で手動の%基準に上書き |
| InpShowMarginLevel | 口座全体の現在の証拠金維持率を表示 |
| InpShowAccountDetails | 口座全体の残高・有効証拠金・必要証拠金・余剰証拠金を表示（初期値: 有効） |
| InpShowCurrentProfit | 口座全体の現在の含み損益（MT5のACCOUNT_PROFIT）を表示（初期値: 有効） |
| InpCurrentProfitColor / InpCurrentLossColor | 現在損益のプラス・マイナス表示色（初期値: 青・赤） |
| InpMarginCallColor | 維持率がマージンコール基準以下の表示色（初期値: 赤） |
| InpMarginWarningPercent / InpMarginWarningColor | 維持率の警戒表示基準と色（初期値: 400%未満で黄色） |

## 損益分岐・ロスカット推定レート

損益分岐は「現在チャートの銘柄」の合計損益がゼロになる価格です。TP/SL合計の全銘柄設定とは独立しています。設定に応じて現在Swapと入力済み決済手数料を反映します。売りのみはAsk、買いのみはBid、両建ては現在スプレッドを固定したBid換算で表示します。

ロスカット目安は、現在の口座全体の必要証拠金を固定し、MT5口座から取得した強制ロスカット基準に有効証拠金が達するように現在チャート銘柄だけが動いた場合の価格です。口座の `ACCOUNT_MARGIN_SO_MODE` が割合なら基準は%で、金額なら口座通貨で扱います。`InpStopOutPercent` に正数を指定した場合のみ、その%を計算に使います。基準が取得できなければ推定レートは「基準取得不可」と表示します。他銘柄の損益・為替・スプレッド、建玉数量は固定します。現在までのSwapは口座有効証拠金に既に含まれるため、InpIncludeSwap=falseの場合もロスカット計算から除外しません。決済手数料も強制決済前の有効証拠金から追加で控除しません。

これは最初の強制決済が始まる仮定上の目安であり、全ポジションがその価格で決済される意味ではありません。必要証拠金の価格連動・レバレッジ変更・SL/TPでの途中決済・他銘柄の変動・ギャップにより変わります。設定済みSL/TPが先に執行されれば建玉が変わるため、表示レートは実際の経路を表しません。

レート推定は損益通貨と口座通貨が一致する線形契約のみ対応します（現在のUSD口座・BTCUSDは対応）。対応外や完全両建ては「計算不可」等で表示し、推定値を捏造しません。必要証拠金0、保有なし、正の価格に解なしも区別します。

計算式: 維持率=有効証拠金÷必要証拠金×100。基準が%なら有効証拠金の目標値=必要証拠金×強制ロスカット基準÷100。基準が口座通貨ならその金額を有効証拠金の目標値にします。マージンコールも同じ単位で取得し、%基準なら維持率、金額基準なら有効証拠金と比較します。
2026-10-25のMT5実行ログでは、口座基準は割合モード、マージンコール80%、ストップアウト20%、手動上書きなしでした。これらは口座の現在設定から再取得され、固定値として埋め込まれていません。
参考: https://www.mql5.com/en/book/automation/account/account_margin

## 計算の意味

- 保有ポジションのみ。予約注文は対象外。
- 建値から各ポジションの設定TP/SLで決済した場合の損益。現在値からの追加損益ではありません。
- TPを分けている場合は、それぞれの価格で決済した結果を合算。
- SLが利益側にある場合は、その利益をSL合計に表示。TP合計へ付け替えません。
- TP/SL未設定があれば「未設定 n件・一部合計」と表示し、数値を警告色にします。
- 対応外の計算方式や必要データ不足なら「計算不可」。誤ったゼロに置き換えません。
- USD建て口座のBTCUSDのような線形契約は、価格差×契約サイズ×lotで計算。口座通貨と損益通貨が異なる場合は現在の口座通貨建てティック価値を使用。
- スプレッドは決済価格へ追加で引きません。指定TP/SL価格での約定を前提とします。滑り・ギャップ・途中の強制決済・将来の為替変動を予測しません。
- 将来スワップ・支払済みのエントリー手数料は含みません。決済手数料は入力した額のみ。
- 円換算は表示時の参考レート。1時間以上古いレートなら日時（MT5サーバー時刻）を併記。
- 100msごとに更新します。値が変わったラベルだけを書き換え、文字幅が変わったときに列揃えを再計算します。

`verification/tp-sl.json` と `verification/rates.json` に独立した算式の検証とMT5ポジションの照合値を保存しています。

## 仮TP/SLの試算

`PositionScenario` は `PositionMonitor` と別の読み取り専用スクリプトです。MT5の `MQL5\Scripts\Custom\PositionScenario.ex5` に配置し、必要なときだけ現在のチャートで実行します。実行後は右上に結果を残し、再実行すると前回の表示を更新します。`InpClearResult=true` で表示だけを消せます。タイマーは使いません。

`InpTrialTP` と `InpTrialSL` に仮の価格を入力します。0ならその項目の仮試算は行いません。現在のチャート銘柄の保有ポジションについて、現在設定、全件を仮価格に変更、半数だけを仮価格に変更した場合の合計損益と、現状からの差額をTP/SL別に表示します。TP到達とSL到達は別々の仮定で、価格到達の順序は予測しません。実際のTP/SL・注文・ポジションは変更しません。

半数は、各ポジションの**現在TPでの見込利益が小さい順**に選びます。奇数件では端数を切り捨て、同額ならチケット番号の小さい順です。TPとSLの半数試算には同じポジションを使い、残りのポジションには現在設定を適用します。現在TPが未設定または計算不可なら半数を選べないため、半数試算は「算出不可」と表示します。

損益はMT5の `OrderCalcProfit` で口座通貨建てに計算し、設定に応じて発生済みスワップと入力した将来の決済手数料を反映します。現在TP/SLが未設定の場合、その合計や差額は「算出不可」です。将来のスワップ、滑り、価格到達前の部分決済、ブローカーによるTP/SL価格の許可判定は含みません。結果は実行時点のスナップショットなので、ポジションやスワップが変わったら再実行してください。
